# agnostic-gaming-mode
Custom Gamescope Session that uses a modified version of Gamescope.

Agnostic Gaming Mode is designed to work on any flavor of CachyOS. Improved support for other distributions will be added in the future but it will need to be installed manually on them for now.

Online Installation:

Download the newest version from Releases and run:
```
git clone https://github.com/sawyer-roberts/agnostic-gaming-mode.git
cd agnostic-gaming-mode
chmod 755 install.sh
./install.sh
```
